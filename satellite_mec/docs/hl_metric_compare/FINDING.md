# 累计寿命损耗指标核对（方案甲，5 种子 × 5400 槽，×192/25 投影）

**结论：不要采用 GPT 提议的"投影割线"指标；它在当前 36 kJ 饱和下会把主结果打翻。
现有"切线"指标与正确实现的"未投影割线"（真非线性 L）数值等价（<1%）、排序一致——
可放心沿用切线，并用等价性堵住"只报一阶代理"的质疑。**

## 三种指标对比（cumHL，越低越好）

|---|---|---|---|---|---|
| **BLA-MAPPO** | **182.4 (①)** | 129.5 (③) | **182.7 (①)** | 16.0% | 13.8% |
| LyDRL-DoD | 536.7 (⑤) | 146.7 (⑤) | 537.8 (⑤) | 34.9% | 25.6% |
| MHSPO | 526.5 (④) | 127.9 (②) | 527.6 (④) | 24.6% | 21.6% |

- 投影割线排序：LSO < MHSPO < **BLA-MAPPO** < GDCO < LyDRL-DoD → **BLA-MAPPO 掉到第3**

## 为什么投影割线会坏

DoD 更新有区间投影 $\Pi_{[0.1,0.8]}$。反事实两支
`DoD_with = Π[before+Δbase+Δcomp+Δtrans−Δsolar]`、`DoD_without = Π[before+Δbase−Δsolar]`
在卫星贴 0.8 上界（且地影无太阳能）时**双双被截到 0.8 → ΔL = L(0.8)−L(0.8) = 0**。

实测：**16%–35% 的"有可控能耗"的星-槽被这样清零**。清零越多的方法（把电池压到天花板越狠者：
LyDRL-DoD 贴边 25.6%、MHSPO 21.6%）反而"免罚"越多，割线值被人为压低。
**BLA-MAPPO 恰恰是把 DoD 压得最低（贴边仅 13.8%）——本该是电池感知方法的优点，
却因清零红利最少，在投影割线下失去领先。该指标在惩罚"最会保护电池"的方法，方向错误。**

## 为什么未投影割线 ≈ 切线

去掉损耗核算里的上界重截断后，非线性割线 $\mathcal L(DoD_{with})-\mathcal L(DoD_{without})$
与一阶切线 $\mathcal L'(DoD)\cdot\Delta DoD$ 数值等价（差 <1%）：因为**单槽 $\Delta DoD$ 极小
（~2e-3 量级）**，非线性曲率在单步内可忽略，割线退化为切线。凸性带来的"星座级均衡"收益
来自访问到的**不同 DoD 状态**（由 $\mathcal L'(DoD)$ 随状态变化捕捉），两指标都能体现。

## 给论文的建议

1. **主图沿用切线指标**（现有 `figures_paper/cumulative_hl.png` 无需重跑重画）。
2. 正文把口径**如实**写成"累计一阶边际寿命损耗"；**删掉/弱化**"按非线性 $\mathcal L$ 由真实轨迹计算""与训练一阶代理相互独立"两处（与代码不符）。
3. 可加一句 + 附录一张小图：**"一阶边际累计与非线性 $\mathcal L$ 割线（未截断）在本实验中一致到 <1%（见附录），故一阶代理是非线性损耗的忠实度量"**——用数据主动堵住"只报线性代理"的审稿质疑。
4. **不要**采用 GPT 的投影割线。
5. 若坚持要"非线性 L"字样，用**未投影割线**（本目录脚本已实现），数值/排序与切线一致。
