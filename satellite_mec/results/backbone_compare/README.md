These values are **pilot diagnostics, not final scientific conclusions**. They come from one random seed and the curves are visibly noisy. The formal convergence comparison is planned as **32K physical slots × 5 paired seeds**, after which the primary output should be a mean ± std evaluation-return curve plus Final Return, AUC, T90 and final standard deviation.

## Which files should be used for plotting?

For the current pilot, use `pilot_8k/curves_seed0.csv`. It is a long-form, plotting-ready table containing algorithm, seed, training slots, evaluation episode return, completion rate, DoD and health-loss statistics.

For exact reproducibility and audit, use the four per-algorithm `seed0.json` files; they preserve the selected hyperparameters, common protocol and every evaluation checkpoint produced by the cloud run.
